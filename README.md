# Travel Paradise — Travel Website

A responsive travel website recreated from the provided project demo video. Built with **HTML structure, CSS, JavaScript, and PHP**.

## Features
- Responsive navigation and hero section
- Featured travel destinations with images, prices, and ratings
- Country filter for destinations
- Booking form with required-field validation and dynamic total-price calculation
- Contact form with basic server-side validation
- Simple admin dashboard preview
- Responsive layout for desktop and mobile

## Technologies
- HTML5
- CSS3
- JavaScript
- PHP (sessions and form handling)

## Project files
- `index.php` — home page, destinations, about and contact sections
- `booking.php` — booking form and price summary
- `contact.php` — contact form validation and demo response
- `admin.php` — sample admin dashboard UI
- `style.css` — responsive styling
- `script.js` — navigation, total calculation and small UI interactions

## Run locally
1. Install PHP 8 or later.
2. Open a terminal in this folder.
3. Run: `php -S localhost:8000`
4. Visit `http://localhost:8000`

PHP is required for the forms and `.php` pages. A static GitHub Pages site does not execute PHP; use a PHP hosting service for a live PHP deployment.

## Demo limitations
This is a front-end/backend demonstration. It does not connect to a database, send real emails, process payments, or create real reservations. The admin dashboard has no authentication and is for demonstration only. Destination images load from Unsplash and require an internet connection.
